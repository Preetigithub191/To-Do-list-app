# TODO list Application

A basic To-Do List web app built with HTML, CSS, and JavaScript. Users can add, delete, and mark tasks as completed. Tasks are dynamically displayed and managed using JavaScript. The app features a clean, responsive UI and stores data locally for persistent task management.
